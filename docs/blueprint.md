# **App Name**: Playwright Report Exporter

## Core Features:

- CLI Export Command: Adds a CLI command to export test execution reports. Supports specifying export format (PDF or JSON) and test run (latest or specific run ID).
- PDF Report Generation: Generates a visually polished PDF report with a modern layout, summary charts, and status badges. Includes comprehensive test information.
- JSON Report Generation: Generates a machine-readable JSON report containing all test execution data, suitable for CI/CD integration.
- Test Information Aggregation: Collects test run ID, execution date/time, total tests, pass/fail/skip counts, test names, descriptions, execution duration, failure reasons, error logs, screenshots, and videos to include in reports.
- Error Log Analysis Tool: Analyze error logs generated by playwright test execution in order to suggest potential reasons for failure to the user

## Style Guidelines:

- Primary color: Deep blue (#2E3B55) to convey reliability and professionalism.
- Background color: Light gray (#F0F2F5) for a clean and modern look.
- Accent color: Teal (#45B3A9) to highlight key information and actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif, with a modern, machined, objective, neutral look.
- Use simple, geometric icons to represent test statuses and report sections.
- Modern, clean layout with clear sections for summary, test details, and error information.
- Subtle transitions for report loading and section expansion.
